# Shift Manager

A Discord bot I created to help monitor and display Moderators' activity! Credits to whoever made the a similar system in [Alpine Ascents Roblox](https://x.com/AlpineRBLX).

## Requirements

Python 3.8 or higher.

### Packages

- discord.py
- python-dotenv

This Repository doesn't include the .json files because those contain sensitive information! Just create them and put empty brackets.

## Features

### Shift System
Verify which moderators are actively monitoring the server, logs hours spent on shift.

### Active Hours
Moderators can set their active days and hours, and the bot will remind them when the time comes.

### On-Duty Display
Displays a message in public chat of people on shift and also those in their active hours so server members can ping/DM moderators in case something happens.
